AidePilot

A modern, lightweight API testing client

AidePilot is a Postman-like API client built with React, Node.js, and SQLite. Follow the steps below to install and run the application locally.

Prerequisites

  • Node.js 18 or higher
  • npm 9 or higher
  • A modern web browser (Chrome, Firefox, Edge, or Safari)

Installation

Step 1 — Install dependencies

cd aidepilot
npm install

Step 2 — Seed example data (optional)

Loads a demo workspace with JSONPlaceholder API sample requests. 

npm run seed --workspace=backend

Step 3 — Start development servers

npm run dev

Backend runs on port 3001 · Frontend runs on port 5173

Step 4 — Open the app

Visit http://localhost:5173 in your browser after the servers start.

Other Commands

Command Description
npm run dev:backend Start API server only (port 3001)
npm run dev:frontend Start React app only (port 5173)
npm run electron:dev Run as desktop app via Electron
npm run build Build backend and frontend for production
npm start Run production build (after npm run build)
